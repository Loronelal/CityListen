```
Название проекта
```

```
Smart Audio Guide — персональный аудиогид на основе GPS и ИИ.
```

# `Проблема` 

```
Туристы и жители городов хотят узнавать об интересных местах вокруг себя, но
существующие решения ограничены:
```

- `Готовые аудиогиды (VoiceMap, izi.TRAVEL) покрывают только популярные туристические маршруты. В малоизвестных районах контента просто нет.` 

- `Интернет-поиск неудобен на ходу: читать статьи с телефона во время прогулки небезопасно и некомфортно.` 

- `Google Maps и Яндекс.Карты показывают статические статьи, но не озвучивают их и не адаптируют под контекст прогулки.` 

- `Нет инструмента, который работает по принципу «здесь и сейчас»: пользователь просто идёт, а приложение само рассказывает о том, что рядом.` 

```
Внешние источники данных
```

```
Проект использует каскадную стратегию обогащения данных, где каждый следующий
уровень включается, если предыдущий не дал результата.
```

```
Уровень 1: OpenStreetMap (основной источник)
```

- `Overpass API — поиск объектов (POI) в радиусе от координат пользователя.` 

- `Nominatim — обратное геокодирование (координаты → адрес).` 

- `Даёт «скелет»: адрес, тип здания, nearby-объекты.` 

```
Уровень 2: Wikidata / Wikipedia (обогащение)
```

- `Wikidata SPARQL — структурированные факты о значимых объектах.` 

- `Wikipedia Geosearch API — статьи, привязанные к координатам.` 

- `Наполняет «плотью»: исторические факты, описания, контекст.` 

# `Уровень 3: ИИ-генерация (финальный рассказ)` 

- `Groq API (основной) — высокая скорость генерации, модели Llama.` 

- `Google AI Studio / Gemini (резервный) — бесплатный тариф без карты.` 

- `Создаёт «душу»: связный рассказ на основе фактов.` 

```
OpenStreetMap + Wikidata дают полную свободу: данные можно кешировать, изменять
и комбинировать. Это критично для архитектуры проекта.
```

# `Аппаратная функция` 

```
GPS / геолокация (FusedLocationProviderClient).
```

```
Как встроена в основной сценарий:
```

```
Пользователь нажимает «Начать прогулку».
Приложение запрашивает разрешение на геолокацию.
Сервис подписывается на обновления координат.
```

```
При смещении > 200 метров от последней точки интереса — запрос к серверу → ИИ →
текст → TTS → аудио.
Рассказ кешируется в Room для повторного использования.
```
