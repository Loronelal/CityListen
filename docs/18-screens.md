## Экраны 2–3

### История

- Данные из Room через `GetHistoryUseCase`, группировка по дням: «Сегодня», «Вчера», далее дата.
- Состояния: загрузка, список, пустой список, ошибка сети с показом кеша и повтором.
- Переход к рассказу по `StoryRoute(storyId)`.

### Карта

- Известные места — сохранённые рассказы из истории.
- Состояния: загрузка, карточки мест поверх карты, пустой список, ошибка сети.
- Переход к рассказу по `StoryRoute(storyId)`.

### Переиспользуемые компоненты

`ScreenHeader`, `LoadingState`, `EmptyState`, `ErrorBanner`, `ListCard`, `MapSurface`.

### Типобезопасная навигация

`StoryRoute(storyId: String)` — `@Serializable` data class. Аргумент читается во `ViewModel` через `SavedStateHandle`.
