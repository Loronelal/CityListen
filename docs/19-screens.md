## Экраны 4–6

### Онбординг

- Показывается при первом запуске; факт прохождения хранится в DataStore.
- `ObserveOnboardingCompletedUseCase` управляет стартовым экраном, `CompleteOnboardingUseCase` фиксирует завершение.
- После «Начать прогулку» открывается `WalkRoute`, онбординг удаляется из back stack.

### Разрешение на геолокацию

- `PermissionRoute` объясняет, зачем нужен доступ, и запрашивает `ACCESS_FINE_LOCATION` /
  `ACCESS_COARSE_LOCATION` через `ActivityResultContracts.RequestMultiplePermissions`.
- При согласии `SetLocationConsentUseCase` сохраняет согласие, экран закрывается.
- При отказе открывается `PermissionDeniedRoute` с кнопкой «Открыть настройки».
  После возврата из системных настроек разрешение проверяется повторно на `ON_RESUME`.
- «Не сейчас» возвращает на предыдущий экран без запроса.

### Настройки

- Язык: `ru` / `en`, сохраняется через `ChangeLanguageUseCase`.
- Тема: `SYSTEM` / `LIGHT` / `DARK`, сохраняется в DataStore и применяется в `CityListenRoot`.
- Геолокация: статус согласия; при выключенном доступе открывается экран разрешения,
  при включённом — системные настройки приложения.
- Профиль: переход на `ProfileRoute`.
- О приложении: версия из `PackageManager`.

### Профиль

- Сервер поддерживает только анонимную авторизацию, поэтому профиль локальный, гостевой.
- Пользователь может задать отображаемое имя; оно хранится в DataStore.
- Валидация вынесена в `DisplayNameValidator`:
  - обязательное поле;
  - от 2 до 40 символов;
  - буквы, цифры, пробелы, дефис, апостроф, точка и запятая;
  - пробелы по краям обрезаются, повторяющиеся схлопываются.
- `SaveProfileUseCase` сохраняет только нормализованное валидное имя.
- Ошибки показываются в `OutlinedTextField`, успех — сообщением «Сохранено».

### Оверлей ошибки

- `ErrorOverlayDialog` — модальное окно «Что-то пошло не так» с кнопками «Повторить» и «Закрыть».
- Используется на экране прогулки при ошибке загрузки; после закрытия остаётся
  встроенное состояние ошибки с повтором.

### Тесты

- `DisplayNameValidatorTest` — граничные значения и недопустимые символы.
- `SaveProfileUseCaseTest` — сохранение только валидного нормализованного имени.
- `SettingsUseCasesTest` — онбординг, тема, согласие, язык и профиль.
- `OnboardingViewModelTest`, `PermissionViewModelTest`, `SettingsViewModelTest`,
  `ProfileViewModelTest` — состояния и действия экранов.
